# NYC Taxi Fare Prediction

# Project Overview
This project focuses on predicting NYC taxi fare amounts using a real-world dataset. Machine Learning techniques are applied to analyze trip data, perform feature engineering, and build regression models to estimate fare prices accurately.

#  Problem Statement
Taxi fare prediction is a regression problem where the goal is to estimate the total fare amount based on trip-related features such as distance, pickup time, location, and passenger count.

# Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Scikit-learn  
- Jupyter Notebook  

# Steps Performed

#1. Data Preprocessing
- Handled missing values
- Converted datetime columns
- Removed irrelevant features

# 2. Exploratory Data Analysis (EDA)
- Analyzed fare distribution
- Studied passenger count patterns
- Visualized data relationships

# 3. Feature Engineering
- Extracted pickup hour, day, and month from datetime
- Used trip-related numerical features for prediction

#  4. Model Training
- Linear Regression
- Random Forest Regressor

# 5. Model Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

# Results
- Random Forest performed better than Linear Regression
- Model achieved good predictive performance with low error rate
- R² Score shows strong correlation between features and fare prediction


# Conclusion
This project demonstrates how machine learning can be used to predict taxi fares efficiently by analyzing trip data and applying regression models.


 # Dataset
NYC Yellow Taxi Trip Records Dataset (Kaggle)

# NYC Taxi Fare Prediction

Machine Learning project to predict taxi fares using NYC Taxi Dataset.

## Features
- Data preprocessing
- Feature engineering
- Exploratory Data Analysis (EDA)
- Linear Regression
- Random Forest Regression
- Model evaluation using RMSE and R²

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Kaggle NYC Taxi Dataset
